# Akram Taha Zeyad — academic portfolio

Live website: https://akramtaha98.github.io/

This website uses HTML, CSS, and JavaScript and publishes through GitHub Pages from the root of the `main` branch.

## Update content

1. Open `index.html` on GitHub and choose Edit.
2. Change the biography or research descriptions, or add an article inside `publication-list` using an existing article as a model.
3. Commit to `main`. GitHub Pages publishes the update automatically.

## Update PDFs

Upload or replace a document in `papers/`, retaining its filename to preserve links. The CV lives at `Akram_Taha_Zeyad_Resume.pdf`.

## Design and interactions

- `style.css`: visual design and responsive layouts.
- `app.js`: illustrative retrieval walkthrough, language animation, and research filters.
- No install or build step is required. To preview locally, serve this folder with any static web server.

The retrieval walkthrough is illustrative, not a live model. Manuscript labels do not imply publication or acceptance. No CMS dashboard is connected yet; content can be edited through GitHub's file editor.
